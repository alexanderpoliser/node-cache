# Fork Maintenance Status

Last updated: 2026-02-26

This fork is actively maintained with a pragmatic scope:
- Fix correctness bugs and regressions.
- Keep dependencies and CI reasonably up to date.
- Keep API behavior stable unless a major version is planned.

- Issues are triaged by priority (`P0` to `P3`).
- High-priority bug reports with minimal reproductions are handled first.
- Feature requests are accepted when they do not degrade simplicity/performance.

- Keep release cadence predictable under `RELEASE_POLICY.md`.
